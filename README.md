# prince-dev-space

A modern, responsive personal developer portfolio built with Next.js (App Router), TypeScript, and Tailwind CSS. Designed to showcase production-ready web applications, technical competencies, and developer workflows.

---

## 🛠️ Tech Stack & Architecture

* **Framework:** Next.js (App Router)
* **Language:** TypeScript
* **Styling & UI:** Tailwind CSS, Lucide Icons
* **State & Options:** React Context API (`ThemeContext`), LocalStorage Persistence
* **Deployment:** Vercel

---

## Core Features

* **Featured Projects Showcase:** Interactive filter tabs showcasing core applications (*SkyPulse Weather App*, *Dine Luxury Restaurant*, *Sneakers E-commerce*) with live demo links and source repositories.
* **Tech Stack Matrix:** Categorized grid presenting core technical competencies across frameworks, styling tools, web APIs, and developer tooling.
* **Technical Milestones Timeline:** Grounded execution timeline detailing hands-on technical progress and project delivery.
* **Direct Outreach Suite:** Copyable email utility with direct mail actions and downloadable resume access.
* **Theme System:** Seamless Dark/Light theme switching with persistent local storage retention.

---

## ⚙️ Local Development Setup

To run this portfolio locally on your machine:

```bash
# 1. Clone the repository
git clone [https://github.com/YOUR_GITHUB_USERNAME/prince-dev-space.git](https://github.com/YOUR_GITHUB_USERNAME/prince-dev-space.git)

# 2. Navigate into the project directory
cd prince-dev-space

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
